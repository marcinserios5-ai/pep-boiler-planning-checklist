# Boiler replacement planning checklist

A small public checklist utility prepared by Pure Energy Project Limited. It helps homeowners record the brief, compare quoted scopes and organise project handover questions.

## Use

Open index.html in a browser. Tick a point when you have noted it for your project. Print the checklist or clear the selections. No installation specification is generated and no information is submitted.

## Project files

- index.html: standalone page, styles and interaction code.
- README.md: this project documentation.

Selections are temporary and reset when the page reloads. The tool has no tracking or form submission.
